# AI Tic-Tac-Toe Using Minimax Algorithm

## Project Overview

This project is an **AI-based Tic-Tac-Toe game** developed using Python. The system allows a human player to play against an AI opponent.

The AI uses the **Minimax Algorithm** to evaluate possible moves and select the best available move. This allows the computer to play strategically and makes it difficult for the human player to defeat the AI.

## Features

* Human vs AI gameplay
* AI-powered decision making
* Minimax algorithm
* Automatic winner detection
* Draw detection
* Interactive game board
* Restart game option
* Google Colab implementation

## Technologies Used

* Python
* Google Colab
* Minimax Algorithm
* Recursion
* Lists
* Conditional Statements
* Functions
* IPyWidgets

## How It Works

1. A 3×3 Tic-Tac-Toe board is created.
2. The human player uses **X**.
3. The AI uses **O**.
4. The player selects an available position.
5. The AI evaluates possible future moves using the Minimax algorithm.
6. The algorithm assigns scores to possible game outcomes.
7. The AI selects the move with the best possible result.
8. The system checks for a winner or draw after every move.
9. The game continues until a player wins or the board becomes full.
10. A restart option allows the user to start a new game.

## Minimax Algorithm

The Minimax algorithm is a decision-making algorithm commonly used in game-playing Artificial Intelligence.

The AI considers possible future moves and chooses the move that provides the best outcome for itself while assuming that the opponent will also make the best possible move.
